Independent researcher and founder building the compiler layer for agentic AI. Third-year Computer Engineering student in Tehran, working across ML compilers, training dynamics, and agentic infrastructure — with a running interest in mechanistic interpretability and quantum computing.

### Now

- **[Tochal](https://tochal.vercel.app)** — an open-source ML compiler for agentic AI workloads. DAG-based IR, three optimization passes (parallelism extraction, LLM call merging, speculative branch execution), async runtime on a Groq / Llama 3.3-70B backend. Measured **1.70×–1.89×** speedups.
- **Research** — a manuscript on how curriculum ordering shapes generalization in low-capacity models, spanning 450+ models across four architectures. Under review, NeurIPS 2026.
- **Next** — pursuing a funded, direct PhD (ETH Zürich SPCL / EPFL).

Earlier open-source work: **GradScope**, a PyTorch diagnostics library for gradient inspection, and **Flare**, a two-line AI agent debugger with a terminal UI and browser-based DAG visualization. [Browse all repos →](https://github.com/Mahdi-Rashidiyan?tab=repositories)
